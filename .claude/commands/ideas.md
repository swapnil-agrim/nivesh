Find investment ideas for: $ARGUMENTS

The handler is `nivesh ideas $ARGUMENTS`. It screens the loaded universe with a preset, runs a
deep committee on the shortlist, ranks by conviction and prints the top ideas, then saves a
checked report and records each call in the ledger. Interactive sessions cannot run shell
commands, so tell the owner to run that line in a terminal; the cost estimate is printed before
any model spend and a hard cap limits the number of runs. Output is an example for the owner to
judge, not advice.
