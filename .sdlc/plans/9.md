## Conventions fixed here (the ADR records them; tests assert them)
- Window and seed conventions (TA-Lib-style where identical): SMA simple; EMA alpha = 2/(N+1) seeded with the SMA of the first N closes; RSI(N) Wilder smoothing seeded with the simple mean of the first N gains and N losses, then `avg = (avg*(N-1) + x)/N`; ATR(N) Wilder, seeded with the mean of the first N true ranges starting at bar index 1 (bar 0 has no previous close); MACD(12,26,9): EMA(fast) and EMA(slow) each seeded with the SMA of their own first N closes, MACD line starts where the slow EMA starts, signal = EMA(9) seeded with the SMA of the first 9 MACD values, histogram = MACD - signal. (TA-Lib seeds the fast EMA of MACD differently, so MACD may differ from TA-Lib in a late decimal on short histories; recorded as D3. 1e-6 is asserted against the hand-derived references below.) ROC = close/close_n - 1 over 63/126/252 sessions; realised vol = sample std dev of simple daily returns times sqrt(252) (same as `mf_returns`); Bollinger(20, k=2) population std, width = (upper - lower)/middle; 50-DMA slope = (SMA50_t - SMA50_{t-20}) / SMA50_{t-20}; weekly trend = 10 vs 40 week SMA of the last close of each ISO week; up/down volume ratio over 20 days = volume on up closes / volume on down closes (None if no down day); 52-week distance uses 252 bars of high/low.
- Long windows: an indicator that needs N bars and has fewer returns `value=None, available=false, reason="need N bars, have M"` (SMA200, ROC 12m needs 253, 52-week needs 252, weekly trend needs 200). Fewer than 200 bars therefore nulls all long-window indicators; short windows still compute.
- **Hand-derived known answers** (the implementer must reproduce these in tests; they are derived without TA-Lib):
  - SMA(3) of 1,2,3,4,5 at the end = 4. EMA(3) of 1,2,3,4,5: seed 2 at index 2, alpha 0.5, then 3, then 4.
  - RSI(3) on closes 10,11,10,12,13,12,14: changes +1,-1,+2,+1,-1,+2; seed avg gain 1, avg loss 1/3; successive (gain, loss): (1, 2/9), (2/3, 13/27), (10/9, 26/81); RS = 45/13; **RSI = 4500/58 = 77.5862068965517...**
  - ATR(3) on (H,L,C) bars (11,9,10),(12,10,11),(13,10,12),(14,12,13),(15,13,14): true ranges from bar 1: 2,3,2,2; seed (2+3+2)/3 = 7/3; next = (7/3*2 + 2)/3 = **20/9 = 2.2222...**
  - MACD(2,3,2) on 1..6: fast EMA from index 1: 1.5, 2.5, 3.5, 4.5, 5.5; slow EMA from index 2: 2, 3, 4, 5; MACD line from index 2 = 0.5 each; signal seed (0.5+0.5)/2 = 0.5; histogram 0.
  - Bollinger width (n=3, k=2) on 1,2,3: mean 2, population sd sqrt(2/3) = 0.816496580927726, width = 4*sd/2 = **1.632993161855452**.
  - Realised vol window 2 on 100,110,99: returns +0.1, -0.1, sample var 0.02, vol = sqrt(0.02*252) = sqrt(5.04) = **2.244994432064365**.
  - ROC, 52-week distance, up/down ratio: closed forms on ramp series (close_i = 100 + i, constant range bars: SMA_n(last) = last - (n-1)/2, ATR = range, RSI = 100).
  - Reverse-DCF invariant: flat cash flow CF, discount r, terminal growth 0, any horizon: value = CF/r (CF=100, r=10% gives 1000), so market cap 1000 implies growth 0.
  - HHI of weights 50/30/20 = 0.38, effective N = 2.631579; days-to-trade: 20-day average volume 100000 at price 50, 10% participation: 500000 per day, size 2000000 gives 4 days.
  - XIRR: closed form for two flows `r = (in/out)^(365/days) - 1`; Microsoft documented example (-10000 on 2008-01-01; +2750 2008-03-01; +4250 2008-10-30; +3250 2009-02-15; +2750 2009-04-01) = 0.373362535 within 0.01% (if the implementation disagrees, verify by NPV substitution before touching the expectation); plus substitution checks (NPV at the result is below 1e-9 relative) for multi-flow vectors.
