## Decisions
- a. Pledge: in `_check_pledge`, directly after `pct = pledge.get("pct_of_promoter_holding")`, return early when `pct` is not a finite int/float, deciding on the TYPE first (never `_dec` first: `_dec` calls `math.isfinite`, which raises OverflowError on an int above ~1e308, and that would escape `validate` and crash the whole ingest). Exact guard, with a short comment (text, bool, list, NaN, inf are unparsable so the mapper stores None; type test before any `_dec`):
  `if (isinstance(pct, bool) or not isinstance(pct, int | float) or pct != pct or abs(pct) == float("inf")): return` (ruff-format puts each `or` operand on its own line). The `_number(...)` call and the `pct is not None and pct < 0` line stay as they are.
  Verified in-process on the guard: "abc", "12.5%", True, [1], None, NaN, inf, -inf all skip (mapper stores None); 1e9, 150, -5, 10**400, -(10**400) all still raise DataQualityError; a `_dec`-first guard gives OverflowError for the last two. Mapper `_latest_pledge` (A:470-482) called alone with 10**400 raises OverflowError via `_dec`, but it is unreachable: `Adapter.fetch` runs `validate` first (`base.py:49-52`), so `validate` fails with DataQualityError and the payload is never cached or mapped. `_dec` is left untouched.
  NaN/inf pledge flips from failed line to None on purpose (named in the test). The fixture pledge has `status: "none"`, which maps an unparsable pct to 0 (A:479-481), so the new tests set `status="unknown"` to assert None.
- b. `_NOT_FOUND = re.compile(r"\b(?:company|symbol|section) not found", re.I)`. The `|no financial statements` alternative is dropped (it widened matching on unrecorded wording; `Error: No financial statements for "X"...` alone was not matched by the old regex either). Verified against every recorded text in `tests/fixtures/market/tapetide_misc.json`: `err_unknown_symbol` matches ("Company not found"); `err_bad_section`, `err_bad_token_401`, `err_no_token_401` do not. Also matches "Error: Symbol not found: X", "Error: Section not found: X"; does not match "Error: Not found (tapetide-api): token not found" or "...: nothing here" (old regex matched both).
- c. `today or ist_date(utcnow())` with `nivesh_core.timeutil.ist_date`. M:653 (`ingest_estimates`, US-only) is left alone.
- d. 3c: all four sections fail on a NOBSE alias; exactly 4 calls, all `get_financials` with a `section`; no snapshot, no `get_shareholding`.
- e. 3b pins CURRENT behaviour, no source edit. Verified outputs for shares 1000, eps 10 (attributable 10000): net income 12000 gives "...(Tapetide Net Profit, 20.0% above EPS x shares...", 8000 gives "...Net Profit, -20.0% above...", 9800 (-2%) and 10300 (exactly +3%) give None.
