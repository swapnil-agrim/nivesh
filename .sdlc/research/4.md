## Constraints & unknowns
- Unverified: keyring Linux Secret Service/headless behaviour in Docker (no backend); the plan should use env/secret injection there (matches `get_secret` order). Not run here.
- Unverified: how Agent SDK `claude_agent_sdk` exposes per-message usage/cost for token and model recording (`ResultMessage` fields, `total_cost_usd`, `usage`); the Plan must read the pinned SDK source/docs before designing the trace schema and INR conversion (a USD to INR rate is a new input).
- Unverified: availability of `age` or `gpg` on dev/CI hosts; prefer `age` via the `pyrage`/`age` binary vs `cryptography`; decide in Plan, pin per NFR-6.
- Constraint: NFR-3 (no PII in prompts, outputs, logs, reports), NFR-5 (0600 session files), NFR-9/20 (determinism, replay), NFR-13 (cap, degrade), NFR-16 (mac+Linux CI matrix; Docker), CR-1/NFR-1 (zero write tools), CR-2 (egress IP check, report not retry), CR-8 (5-year retention vs ST-13.6 30-day backup retention: not contradictory; backups rotate, ledger is retained).
- Constraint: tests must not contain credential-looking or PAN-like literals; build them by string concatenation (the commit secret-scanner refuses such files), e.g. `"ABCDE" + "1234" + "F"`, `"sk" + "-" + "x" * 20`, `"+91" + "98765" + "43210"`.

## Lane rationale
Large. Footprint: 19 sites across 5 packages (core, mcp, agents, cli, plus CI/ops), 3 new persisted shapes (trace JSONL, run table migration, config price/cap), 1 changed contract (every MCP tool envelope now redacted), new boundary layers (redaction middleware, budget gate, untrusted-content wrapper), 8 stories of which 3 have unmet upstream dependencies. Recommend splitting at Plan into slices:
- (A) 13.1 + 13.2 + 13.7 (secrets CLI, redaction + scanner, safety test): security core, no new upstream needs.
- (B) 13.3 + 13.4 (run dir, trace, migration 0002, cost meter, `status`): observability.
- (C) 13.5 + 13.6 (Docker, VM guide, egress check, backup/restore).
- (D) 13.8 (delimiter wrapper + guard; verdict-invariance eval deferred to ST-12.6).
Defer explicitly: full numeric replay (E6), verdict-invariance eval (ST-12.6/ST-7.1), scheduler, HDFC broker IP registration, broker-class introspection beyond an empty-set check (no broker classes yet).
