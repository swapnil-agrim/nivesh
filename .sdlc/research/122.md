## Goal in one paragraph
`nivesh ta NSE:RELIANCE` and `nivesh fa RELIANCE` must give real numbers from live public data in a fresh data dir. Four failures block that: (1) `master build` sources (BSE 404, AMFI 302, SEC needs a secret), (2) the NSE holiday list is nearly empty so `market prices` hard-fails on 2025, (3) one bad bhavcopy row rejects the whole day, (4) `ta` shows "need 200 bars, have 0" only as a consequence of (3). Each needs a failing-first fixture test, then a live run.

### Failure 3 root cause (verified on 274 real NSE bhavcopy files, 2025-09-01..2026-10-09)
- Real files hold 119 rows violating `check_ohlc`, **all series `T0`** (trade-to-trade segment; open/high/low print a single limit price, close is outside), across 54 files. Examples: IDEA T0 on 2025-09-04 (O=H=L=6.65, C=6.61), HYUNDAI, OLAELEC, TATASTEEL, PNB. RELIANCE itself has T0 bad rows on 2025-11-21 and 2026-04-23 (its EQ rows are fine).
- `parse_bhavcopy` skips series not in `EQUITY_SERIES` before validating, so the T0 rows never reach `check_ohlc` there. The rejection comes from `validate_payload` (prices_in.py:304-314), called by `Adapter.fetch` -> `validate` (base.py:46-47) before `cached_fetch` caches. It re-parses the entire file with `series=None` and `_AnyId` (accepts every symbol), so any bad row in any series raises `DataQualityError` and the day is lost. `Run.get` re-raises `DataQualityError` (market_ingest.py:108-109), aborting the whole `ingest_prices`.
- Also bad-row policy exists in `parse_bhavcopy` for the wanted security (fatal, correct per issue) and BSE (`series=None`, uses id map so only the requested row).
- UDiFF header on wire: `TradDt,BizDt,Sgmt,Src,FinInstrmTp,FinInstrmId,ISIN,TckrSymb,SctySrs,XpryDt,...,OpnPric,HghPric,LwPric,ClsPric,LastPric,PrvsClsgPric,...,TtlTradgVol,...` (fixture `tests/fixtures/market/nse_bhavcopy.csv` is a trimmed subset of the same names, fine).
- Fix shape for Plan: make the validator structural only (columns, parseable date, numeric parse) and skip-and-count row-level OHLC failures with a reason (e.g. `ParsedBars.skipped_bad: Counter[reason]` or list), surfacing the count/reason in `PriceReport` (already has `flags`, `failed`) and in `nivesh market prices` output; only rows whose key is in `ids` raise. Since `validate_payload` has no id map, simply drop OHLC checking from it (or make it tolerant).

## Correct live URLs and wire formats (verified 2026-10-13 by read-only curl)
- NSE equity list `https://nsearchives.nseindia.com/content/equities/EQUITY_L.csv`: 200, header `SYMBOL,NAME OF COMPANY, SERIES, DATE OF LISTING, ..., ISIN NUMBER, FACE VALUE` (note leading spaces in some headers; `_rows` strips them). Already works (2606 rows per issue).
- AMFI NAVAll: use `https://portal.amfiindia.com/spages/NAVAll.txt` (200, `text/plain`, header `Scheme Code;ISIN Div Payout/ ISIN Growth;ISIN Div Reinvestment;Scheme Name;Plan;Option;Net Asset Value;Date`); `parse_amfi` OK as is (18150 rows). `www.amfiindia.com/spages/NAVAll.txt` 302s to it.
- BSE master: no working public scrip-list CSV. Working public file is the BSE UDiFF bhavcopy `https://www.bseindia.com/download/BhavCopy/Equity/BhavCopy_BSE_CM_0_0_0_{YYYYMMDD}_F_0000.CSV` (200, plain UA, e.g. 20260109, 4757 lines; the same URL `prices_in.BSE_CSV` already uses). Columns include `FinInstrmId` (BSE scrip code, e.g. 500325), `ISIN`, `TckrSymb` (RELIANCE), `SctySrs` (group A/B/T/...), `FinInstrmNm` (RELIANCE INDUSTRIES LTD.). A BSE master can be derived from the latest available day's file (walk back until non-404). Gives symbol, name, ISIN, bse_code; no industry. This is the option I recommend (alternative: drop BSE master and report it as unavailable, but then `fa` for India has no `bse_code`).
- SEC: `https://www.sec.gov/files/company_tickers_exchange.json` works with a contact UA (200, `{"fields":["cik","name","ticker","exchange"],"data":[...]}`), matches `parse_sec`.
- NSE bhavcopy `https://nsearchives.nseindia.com/content/cm/BhavCopy_NSE_CM_0_0_0_{YYYYMMDD}_F_0000.csv.zip`: 200 for sessions, **404 on holidays** (a reliable holiday oracle); plain UA works; each unzipped file about 550 KB (275 sessions about 150 MB of cached text in `cache_entry`, see debt).
- NSE indices `https://nsearchives.nseindia.com/content/indices/ind_close_all_{DDMMYYYY}.csv`: 200, header matches `parse_indices`.
- Yahoo chart `query1.finance.yahoo.com/v8/finance/chart/RELIANCE.NS`: 200 with plain UA.
- NSE official holiday feed (for refreshing the list, needs a cookie from a prior hit; browser-like UA): `https://www.nseindia.com/api/holiday-master?type=trading` returns only the current year, key `CM`.
