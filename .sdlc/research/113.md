## 2. Scanner internals

- Location: `nivesh_core/pii_scan.py` (`Finding(kind,start,end)`, `scan_text`, `scan_paths`). It owns no patterns: it iterates `nivesh_core/redact.py::PATTERNS` (single source shared with `redact_text`), sorted by `(start, kind)`. It never returns matched text.
- `scan_paths(paths)` reads each file as UTF-8, skips binary or unreadable files, and scans **line by line** (file *names* and directories are never scanned, only contents).
- No allow-list, no thresholds beyond the regexes. Relevant patterns (`_L = (?<!\d)(?<!\d\.)`, `_R = (?!\.?\d)`):
  - `digits`: `_L \d{9,18} _R`. A run of 19+ digits matches nothing (every start is blocked by the lookbehind or the lookahead), a decimal fraction (`0.600000000000003`) is skipped, a run of 9 to 18 bounded by non-digits (letters, `_`, `/`, `-`, `=`) is flagged.
  - `phone`: `_L (?:(?:\+91[\s-]?)?[6-9]\d{4}[\s-]\d{5} | [6-9]\d{2}-\d{3}-\d{4} | 0\d{2,4}-\d{6,8}) _R`.
  - others: `bearer`, `sk_key`, `pan`, `email`, `dp_id` (`IN\d{14}`), `labelled_id`, `aadhaar` (4-4-4), `address` (`address:.*$`).
- Product callers of `scan_text`: `nivesh_adapters/delivery.py:97` (`blocked_reason`: blocks a delivery whose subject/text/page is flagged), `nivesh_adapters/schedule_jobs.py:160` (withholds a flagged summary line), `nivesh_core/ledger.py:220` and `nivesh_cli/schedule.py:180` (reject a flagged `--note`). `scan_paths` is the `nivesh pii-scan PATHS` command (`nivesh_cli/main.py:112`, prints `path:line:kind`).
- Local reproduction (no repo edit): `scan_text` on `/private/var/folders/n6/<token>/T/pytest-of-runner/pytest-0/test_ideas_run_over_synthetic_0/data` returns one `digits` finding at 42..52 (`2113800000`). A typical dev-Mac token (`.../z4wr58ns2dn0n2dfdq3dxrf80000gn`, run length 5) and a Linux `/tmp/pytest-of-runner/...` path return `[]`. Run lengths 9, 10, 18 flag; 8 and 19 do not.

## 5. Other flake sources the helper must also neutralise
