### 2. Yahoo Finance statements (.NS)
- `v10/finance/quoteSummary/RELIANCE.NS?modules=incomeStatementHistory` (query1 and query2) -> **401** `{"finance":{"error":{"code":"Unauthorized","description":"Invalid Crumb"}}}`. quoteSummary needs a cookie+crumb dance; not usable without one.
- `ws/fundamentals-timeseries/v1/finance/timeseries/{SYM}.NS?type=annualTotalRevenue,...&period1=..&period2=..` -> **200 without crumb or cookie** with `nivesh/0.1`; the same URL with a Chrome UA returned **429** "Too Many Requests" (UA-sensitive rate limit). `.BO` works too. Response: `timeseries.result[].{meta.type, timestamp, <type>: [{asOfDate, periodType 12M|3M, currencyCode, reportedValue.raw}]}`. No `filed_at`/`reportedDate` field.
- Line items present (annual*/quarterly* prefix): TotalRevenue, OperatingRevenue, NetIncome, NetIncomeCommonStockholders, OperatingIncome, PretaxIncome, TaxProvision, EBITDA, NormalizedEBITDA, EBIT, InterestExpense, DilutedEPS, BasicEPS, DilutedAverageShares, TotalAssets, StockholdersEquity, CommonStockEquity, TotalDebt, LongTermDebt, CashAndCashEquivalents, CurrentAssets, CurrentLiabilities, AccountsReceivable, AccountsPayable, Inventory, OperatingCashFlow, CapitalExpenditure, FreeCashFlow, DepreciationAndAmortization, ShareIssued, CashDividendsPaid, GrossProfit, CostOfRevenue. Bank-only: NetLoan, TotalDeposits, ProvisionForLoanLeaseAndOtherLosses, InterestIncome. No GNPA/NNPA/NIM/CASA/CAR, no pledge, no shareholding.
- **Depth fails ST-4.4**: every ticker returns exactly 4 annual points (2023-03-31..2026-03-31) even with `period1=0`; quarterly: RELIANCE/TCS/INFY/ITC 4-5 P&L quarters but only 2 balance-sheet quarters; HDFCBANK 2 P&L quarters (Mar-2025, Jun-2025), balance sheet 4. Balance-sheet and cash-flow quarterly are largely absent. 4 annual points give a 3y CAGR at most (default `fa.growth_years` = 3 needs 4 points, `nivesh_core/analysis_config.py:111`; `fa.py:170-173`), no 5y.
- **Quality defects seen**: INFY returns `currencyCode: USD` (FY26 revenue 20.158B USD, not INR; rows would be mislabelled INR by a naive mapper); ITC quarterly series has Dec-2025 values identical to Mar-2025 (19,918.2 cr revenue and 4,931.2 cr profit twice) and no Sep-2025; HDFCBANK FY23 diluted EPS 88.7 vs FY24 44.2 (not adjusted for the 1:1 bonus) and TotalAssets 52.6 lakh cr vs NSE consolidated 49.08 lakh cr; HDFCBANK FY26 net income 70,479 cr vs NSE standalone 74,671 cr and consolidated 76,026 cr (matches neither; its FY25 67,351 cr matches standalone); ITC revenue 78,213 cr vs NSE consolidated 89,913 cr (Yahoo nets excise/other).
- **Terms**: `https://legal.yahoo.com/us/en/yahoo/terms/otos/index.html` (200): bans accessing or collecting data "using any automated means ... robots, spiders, scrapers, data mining tools ... for any purpose without our express, prior permission", and any commercial reuse. yfinance README: "not affiliated ... intended for research and educational purposes ... the Yahoo! finance API is intended for personal use only ... refer to Yahoo's terms". So yfinance's disclaimer is a personal-use claim that the ToS itself does not grant. `https://query1.finance.yahoo.com/robots.txt` -> `User-agent: *` / `Disallow: /`. Verdict: reject for fundamentals (and the price adapter that already calls `query1.../v8/finance/chart` has the same exposure, which ADR-0005 accepted for prices only; note it).

### 4. Tapetide MCP (named in PID section 12 and ADR-0005 fallback)
- Repo `Tapetide-hq/tapetide-stock-research-mcp`: MIT licence for the bridge; remote MCP `https://mcp.tapetide.com/mcp` (OAuth Google, or an Authorization header using the Bearer scheme with the free token from tapetide.com/settings/tokens), local `npx tapetide-mcp` with `TAPETIDE_TOKEN`.
- Unauthenticated `POST tools/list` -> 200, 55 tools. `get_financials` description (verbatim facts): sections `quarterly` (quarterly P&L, ~13 quarters), `profit_loss` (annual), `balance_sheet`, `cash_flow`, `ratios` (annual); `section` omitted = all sections trimmed to latest 5 periods, `periods` up to 40; per section `periods` (oldest first), `data {row: {period: value}}`, `pct_changes`, `row_order`, `availability[]` giving `available_from` per period with `basis: "reported"` (real declaration date) or `"estimated"` (regulatory-lag estimate). Caveat stated by the vendor: values are the latest reported figures and may include later restatements; only the timing is original. Also `get_shareholding` (promoter/FII/DII/public by quarter) and `get_promoter_pledge` (pledge % by quarter plus events). Symbol argument is the NSE-style symbol ("RELIANCE", "TCS").
- Limits (README + pricing page): free plan 50 successful tool calls/day, 1,000/month, burst 60/min; only successful calls count; denials return `isError: true` JSON-RPC results with `Retry-After`. One `get_financials` call without `section` returns all five sections, so one call per company is enough (about 3 calls per company with shareholding and pledge; 50/day is ample for a watchlist of tens).
- **Terms** (`https://tapetide.com/terms`, section 6 and 7): prohibits automated scraping "outside of the provided MCP server and API", redistribution or commercial exploitation of data, building a competing service or reselling, circumventing rate limits, sharing tokens. Using the MCP/API from a personal tool is within terms. Data is disclaimed ("may be delayed or contain errors"; third-party sources, which are presumably the exchanges). Verdict: terms-compliant for personal use; requires a free account/token (owner action; token goes in the secret store, never the repo).
- **Not verified live**: actual row names, units (crore vs absolute), bank-specific rows, depth of annual history, accuracy vs filings, restatement behaviour. The spike must measure them; I did not create an account or call a token-gated tool.

## Tech debt and risks
- **TD-1** `fundamentals_in.py` TAGS/D3 map and date-based period classifier were never validated against real files (ADR-0005 D2/D3 deferred); real legacy files break the classifier (BR-3). Debt regardless of source choice.
- **TD-2** ADR-0005 is provisional and its desk table never ran the 30-company sampling (ST-4.1). The task's ADR can satisfy the evidence requirement only partly: 5 large caps (not 30) and no Tapetide live numbers without the owner's token.
- **TD-3** Existing code already uses ToU-restricted hosts (NSE `/api` fiidii and corporate actions; Yahoo chart). The new ADR should record this as an open CR-7 exposure for the owner rather than ignore it. NSE corporate-actions endpoint also 404s (#122 BR-21).
- **TD-4** `fa.py` module doc decision "India operating income is a PBT proxy so EBITDA/ROIC/ROCE/interest cover are unavailable for India" limits value even with full data; a source that supplies real operating profit/EBITDA would let the engine relax it (design question, not blocking).
- **R-1 (top)** Tapetide is unverified live: row names, units, depth (>= 5 annual? annual P&L history length unknown; quarterly ~13), bank rows, consolidated vs standalone, accuracy. A fully mapped adapter built blind would be wrong. Mitigation: owner supplies a free token; a spike (5-10 calls) records real bodies as fixtures before the mapper is written; ADR records spike numbers.
- **R-2** Point-in-time is only partly honest: Tapetide `available_from` may be `estimated` (regulatory-lag), values may be restated latest figures. Must be flagged ("approximate filed_at") and visible in `fa` coverage; `latest_as_of` correctness (no look-ahead) is only as good as that date.
- **R-3** Vendor risk: free tier 50 calls/day (1,000/month), single-vendor dependency, terms can change, data from third parties disclaimed. Mitigation: 7-day TTL, one call per company, quota-denial -> unavailable-with-reason, BSE fallback kept, NSE as owner-decision escape hatch.
- **R-4** Owner decision needed if the Tapetide spike fails: accept the NSE ToU exposure (personal use, low volume, ADR-recorded) vs a paid vendor vs `fa` stays unavailable. The researcher does not recommend NSE under CR-7.
- **R-5** PII/secret hygiene: token must live only in env/keychain (`get_secret`), never in fixtures, traces, cache or ADR; recorded fixture bodies must pass `scan_text` (10-digit runs).
- **R-6** `bse_code` precondition at `market_ingest.py:~336` would still block India `fa` if left in front of the new path; BSE master source is broken (#122).
- **R-7** Today's date matters for tests: use fixed dates in fixtures (FY2026, Mar-2026) so `as_of` logic is deterministic.

## Lane / size
**Medium (upper end), not large**, not small. Reasoning: one new adapter (POST JSON-RPC client + secret + rate/quota handling) mirroring existing `IndiaFundamentals`/`Edgar` shapes; one mapper (rows -> `StatementRow`, in-scope vocabulary already exists, no table or migration change if `filed_at` basis is carried in `source`); rewiring of one branch in `ingest_fundamentals` plus CLI text; ADR-0015 plus its test; new recorded fixtures and about 15-20 tests; live verification on 5 large caps.
