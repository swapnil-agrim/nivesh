# ADR-0003: Tracing, redaction, cost meter, backups (E13)

Status: accepted

- **Run dir**: `<data_dir>/runs/<run.id>/trace.jsonl`, dir 0700, file 0600 (`write_private`: `O_NOFOLLOW`, created 0600). Migration 0002 adds `run_dir, model, prompt_version, input_tokens, output_tokens, paid_data_inr, tier` (ADD COLUMN only) and index `run_started`.
- **Trace JSONL**: one object per line, flushed per record. Fields `seq`, `ts` (UTC ISO), `type` in `start | assistant_text | tool_call | tool_result | engine_call | error | result`. `start` carries `prompt_version` (sha256[:12] of the command file); `model` is only known from the first assistant message, so it appears on `result` (and the run row), not `start`. Payload fields (`text`, `args`, `output`, `message`, engine args/result) pass through `redact_json`; metadata is not redacted because key-name masking would hit `input_tokens`. `result` has tokens, `latency_ms`, `cost_inr`, `cost_source` (`table | sdk | none`).
- **Redaction**: one pattern table (`nivesh_core.redact.PATTERNS`) feeds both `redact_text` and the PII scanner so they cannot drift. Added: email, phone (spaced/`+91`), `IN`+14-digit DP id, labelled DP/client/folio/account ids (must contain a digit, so "account summary" survives), `Address:` to end of line. All mask to `[REDACTED]`; no hashing (removal satisfies "removes or hashes").
- **Digit runs (recall loss decision)**: the blanket 9-18 digit sweep is KEPT at every edge (tool output, recorder, cache, errors, traces) instead of the planned label/whole-value Rule R. Consequence: an unlabelled 9-18 digit number inside free text (for example "volume 1234567890123") is masked; numeric JSON values are untouched. Fidelity loss is accepted over missing a PAN-adjacent account number; revisit with real adapter field shapes.
- **Tool output**: every `ReadOnlyServer` tool envelope has its data redacted; `as_of`, `source`, `stale` are never touched. Contract note: consumers see `[REDACTED]` in place of PII-looking values from now on.
- **Tool safety**: `withdraw` joins `WRITE_VERBS`; suffixes `al/als` catch `withdrawal`. Tool descriptions (docstrings) are scanned for whole-word inflected write verbs ("places", "ordered"); "seller"/"ordering" pass. `.mcp.json` servers must be in `SERVERS` or `R3_ALLOWED_SERVERS` (empty).
- **Cost**: price table in config (USD per million tokens) times `usd_inr`; else the SDK's `total_cost_usd` times `usd_inr`; else 0. Cap is `Profile.monthly_cost_cap`. Month-to-date sums `cost_inr + paid_data_inr` for runs started in the current UTC month.
- **Budget gate (one rule)**: at >=80% of the cap `deep` is downgraded to `quick` unless `--force`; at >=100% `deep` is refused even with `--force` (force never overrides the cap); `brief` and `quick` always run; no cap (0) disables the gate. Warnings go to stderr and `nivesh status` (delivery by notifier is deferred).
- **Backup**: tar of a `sqlite3.backup()` snapshot, the checkpointed DuckDB file and `runs/`, encrypted with the `age` binary to a public-key recipient (`nivesh-backup-<YYYYMMDDTHHMMSSZ>.tar.age`, 0600). Plaintext lives only in a 0700 temp dir removed on failure. Retention prunes by the timestamp in the name (default 30 days). Restore decrypts, extracts only regular files/dirs with names inside the target (members validated by hand, no `extractall`), and refuses an existing Nivesh database or a foreign non-empty dir. The identity is only a `--identity` path.
- **Injection**: `wrap_untrusted` (nonce-tagged block, redacted, source sanitised) plus a `GUARD` system prompt (a plain string, which equals the previous empty default plus the guard).
